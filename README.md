# Demos ✨

An ongoing collection of React Native animations crafted with Reanimated, Gesture Handler, and Skia.

## Quick Start

This is an Expo project. To get started:

```bash
bun install
bun prebuild
bun ios     # for iOS
# or
bun prebuild
bun android # for Android
```

## Project Layout

```
src/
├── animations/   # Animation demos and components
└── navigation/   # Navigation utils and hooks
```
